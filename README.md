# PolicyHawk Web

Next.js frontend for PolicyHawk. Product pages load companies, timelines, change reports, and the tracker from the Nest API. The demo posts to a server route that holds the job secret.

Project handover: [../docs/project-context.md](../docs/project-context.md).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Copy `.env.example` to `.env` and set `JOB_SECRET` to the same value as the API, then restart `npm run dev`.

## Stack

- Next.js App Router
- Tailwind CSS v4 and shadcn/ui tokens
- TanStack Query for API data
- Redux Toolkit for theme, directory filters, the demo session, and toasts

## API

`NEXT_PUBLIC_API_URL` and `API_URL` default to `http://localhost:4000/api` (no trailing slash). The demo button calls `POST /api/demo/simulate` on this app. That route calls `POST /api/companies/test-company/simulate-change` with `x-job-secret`.

`policyhawk-web/AGENTS.md` contains Next.js version rules regenerated by `next dev`. Read that file before changing framework APIs.
